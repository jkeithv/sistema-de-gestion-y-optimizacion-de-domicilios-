# sistema-de-gestion-y-optimizacion-de-domicilios-
Sistema de información para la gestión y optimización de servicios de domicilios en Valledupar.

## Integrantes

- Andrea Laurens

- Katherin jimenez

## Descripción
Sistema de información para gestionar pedidos y servicios de domicilio, apoyando la coordinación entre cliente, central y domiciliario. El diseño contempla ubicación registrada del domiciliario, asignación de servicios y seguimiento de rutas.
