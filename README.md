# sistema-de-gestion-y-optimizacion-de-domicilios-
Sistema de información para la gestión y optimización de servicios de domicilios en Valledupar.

## Integrantes

- Andrea Laurens
- Sherly Corrales
- Katherin jimenez
- Andres Garrido

## Descripción

El proyecto consiste en el diseño y desarrollo de un sistema
de información que permita gestionar pedidos, domiciliarios,
asignación de servicios y seguimiento de entregas.

## Tecnologías

- Java
- PostgreSQL 16+
- Git
- Draw.io

- docs/: documentación
- diagrams/: diagramas
- database/: scripts de base de datos
